About Our Project

Our Predictive Machine Learning Model is specifically built to analyze and estimate laptop market prices. By processing key hardware specifications and brand metadata, the regression model uncovers deeper insights into pricing tiers. This enables buyers and retailers to evaluate fair valuations based on core performance components.

Model Features & Predictors

The regression model calculates laptop price benchmarks by analyzing these critical specifications:

  • Core Specifications: Brand, Operating System (OS), and Warranty
  • Performance & Processing: Processor Type, CPU Details, and GPU (Graphics)
  • Hardware & Storage: RAM (GB), Storage / ROM (GB), and Display Size
